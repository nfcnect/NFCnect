This archive contains the existing Sites application source, database schema/migrations, tests and documentation. It is NOT an independent Cloudflare migration build. ChatGPT authentication and Sites deployment integration remain.

It excludes Git history, credentials, installed dependencies, generated build files and database contents. Existing customer records and balances are not included.

For GitHub: extract the ZIP, then upload the extracted contents (including .gitignore, .npmrc and .openai/) to your private repository. Put package.json at the repository root. Do not upload only the ZIP expecting GitHub to extract it.

Before independent public hosting: replace platform-header authentication with verified Supabase sessions on every protected endpoint, configure your own D1 binding, migrate identity ownership securely, configure the new origin, import verified database data through supported access, and rerun authorization and transaction tests. Do not deploy this source unchanged to a public Worker; its identity-header trust depends on the Sites gateway.
