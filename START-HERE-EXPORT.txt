NFCnect independent-hosting migration

This branch adds Supabase authentication and an independent Cloudflare Workers/D1 build. Read README.md and docs/INDEPENDENT-DEPLOYMENT.md first.

Account setup is still required: provide your own Supabase project, Cloudflare account, D1 database ID, runtime settings and owner email. The deployment helper rejects the placeholder D1 ID.

No live customer data, keys or credentials are included. Existing membership/employee identities require the operator-reviewed mapping procedure; do not automatically link accounts by email. Automated checks are not a substitute for hosted acceptance tests, email delivery, restore testing or physical NFC checks.
